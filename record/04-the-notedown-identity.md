# The Notedown identity

**Observed phase: 11 August 2026**

Writing Desk was renamed Notedown on 11 August. The update added document titles to the application bar, revised menus, and introduced the Notedown mark.

The mark uses a white slash on a blue rounded square, referencing the editor's slash command menu.

The interface changes revised title display and overflow menus, added a route from reading back to editing, and incorporated typewriter scrolling into Focus mode. Delete actions gained confirmation. Find and slash controls received visual updates.

Table grips and edge controls were updated to distinguish table selection and movement from cell editing.

See the [development record](README.md) for dates and provenance.
