# Development record

Notedown grew from a writing surface into a local Markdown workspace. These short records explain the product decisions behind that progression: how a note is edited, where it lives, how it leaves the app, and how the interface communicates change.

This documentation was assembled retrospectively on **14 October 2026**, with a Git history arranged from **11 July 2026**. Commit dates represent that reconstructed documentation history, not original development or release dates. The records below describe work observed from August onward.

| Observed date | Phase | Record |
| --- | --- | --- |
| 1 August 2026 | Page and Markdown surfaces | [The writing surface](01-the-writing-surface.md) |
| 1–6 August 2026 | Local documents and images | [The local library](02-the-local-library.md) |
| 6–10 August 2026 | Reading, copying, and structured Markdown | [Portable words](03-portable-words.md) |
| 11 August 2026 | Notedown identity and interface refinement | [The Notedown identity](04-the-notedown-identity.md) |

These records describe observed work and its intent. They do not claim that every browser or document behaves identically, that a particular version was released, or that an issue cannot recur. Current usage guidance belongs in the user documentation. The application implementation remains outside this public repository.
