# The local library

**Observed phase: 1–6 August 2026**

The document library was added on 1 August. Its sidebar supported creating notes, searching titles and contents, renaming, and switching documents. Markdown imports created new library documents. Recently deleted notes could be restored during a short undo window.

The library stored documents in the browser without requiring an account. Document titles followed the first heading or opening line unless renamed manually.

On 6 August, pasted and dropped images moved into a separate browser database. Documents retained references to those images. Markdown exports therefore contained image references without the image files.

Browser storage remained specific to the profile and site address, with no built-in synchronization. See [privacy and storage](../docs/privacy-and-storage.md) for current backup and recovery guidance.
