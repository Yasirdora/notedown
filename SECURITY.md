# Security

Please do not disclose a vulnerability in a public issue or attach private
documents to a report.

Use GitHub's [private vulnerability reporting](https://github.com/yasirdora/notedown/security/advisories/new)
to describe the affected behavior, reproduction steps, browser and operating
system, and likely impact. Use a minimal invented document where possible.

If that reporting option is unavailable, open an issue asking for a private
contact channel without including vulnerability details.

This repository contains public product materials, not application releases.
There is no versioned application support matrix here. Reports about the
current Notedown implementation and these repository materials are welcome;
response and remediation times are not guaranteed.

For ordinary save warnings, export problems, or rendering bugs with no security
impact, use the bug report form described in [CONTRIBUTING.md](CONTRIBUTING.md).
For storage behavior and backups, read the
[privacy and storage guide](docs/privacy-and-storage.md).
