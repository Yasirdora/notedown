# Notedown

The Markdown page that stays yours.

A browser-based writing app with a typeset page, direct Markdown editing, and
local document storage. Notedown is in development.

## This repository

Product documentation, original examples, and approved product images live here.
Application source code, internal research, and development notes remain private.
This repository does not distribute the app.

## About this history
